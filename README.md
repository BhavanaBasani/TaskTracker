# Task Tracker Application

## 🌟 Overview
The **Task Tracker Application** is a full-stack solution for organizing and managing team projects. Built with **ASP.NET Core** and **Blazor**, it provides real-time task tracking with a modern, user-friendly interface. This project is hosted on **Azure** and utilizes industry best practices in both development and deployment.

## 🚀 Features
- **Back-End**:
  - RESTful APIs with **ASP.NET Core** and **Entity Framework Core**.
  - Secure authentication using **JWT**.
  - Modular architecture for scalability and maintainability.

- **Front-End**:
  - Built with **Blazor WebAssembly** for a seamless single-page app experience.
  - Interactive task boards with drag-and-drop functionality.
  - Fully responsive for desktop and mobile use.

- **Real-Time Updates**:
  - Real-time notifications and updates powered by **SignalR**.

- **Cloud Integration**:
  - Hosted on **Azure App Services** with a relational database in **Azure SQL**.
  - Automated CI/CD pipelines with **GitHub Actions**.

- **Additional Features**:
  - Scheduled reminders for tasks using **Hangfire**.
  - Integrated logging and telemetry with **Application Insights**.
  - Dockerized for consistent development and deployment environments.

## 🛠 Tech Stack
**Languages**: C#, SQL  
**Frameworks**: ASP.NET Core, Blazor WebAssembly  
**Tools**: SignalR, Hangfire, Docker  
**Cloud Platforms**: Azure (App Services, Azure SQL, Application Insights)
